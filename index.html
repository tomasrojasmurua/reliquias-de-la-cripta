Cómo jugar

Explora cada mazmorra y reúne sus tesoros. Empiezas solo con tu látigo: busca el revólver y sus balas.

Las tablillas grabadas en los muros guardan pistas crípticas. Descífralas para abrir los sellos que custodian las cámaras. Cuanto más difícil la pista, más valioso el tesoro.

Algunos muros tienen grietas. Empújalos: cada mazmorra esconde al menos un pasadizo secreto.

Computador

WASD o flechas para moverte, ratón para mirar, clic para atacar, E o Espacio para usar, R para recargar, 1 y 2 o Q para cambiar de arma, Shift para correr, Esc para pausar.

Celular

Arrastra en la mitad izquierda para moverte y en la derecha para mirar. Usa los botones para atacar, usar, recargar y cambiar de arma. Se juega mejor en horizontal.
