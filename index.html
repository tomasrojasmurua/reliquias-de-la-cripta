Colección de tesoros

Cómo jugar

Las mazmorras están a oscuras: tu antorcha ilumina solo lo que tienes cerca. Explora cada mazmorra y reúne sus tesoros. Empiezas solo con tu látigo: busca el revólver y sus balas.

Las tablillas grabadas en los muros guardan pistas crípticas. Descífralas para abrir los sellos que custodian las cámaras. Cuanto más difícil la pista, más valioso el tesoro.

Algunos muros tienen grietas. Empújalos: cada mazmorra esconde al menos un pasadizo secreto.

Cada mazmorra tiene además un laberinto de túneles que cambia cada vez que entras: callejones sin salida, salas llenas de monstruos y unos pocos tesoros escondidos en lo más hondo, a veces tras un muro agrietado.

Computador

WASD o flechas para moverte, ratón para mirar, clic para atacar, E o Espacio para usar, R para recargar, 1 y 2 o Q para cambiar de arma, Shift para correr, Tab o M para ver el mapa, Esc para pausar.

Celular

Arrastra en la mitad izquierda para moverte; empuja el joystick hasta el borde para correr. Arrastra en la derecha para mirar y toca ahí para disparar; toca dos veces y mantén el dedo para disparar sin parar mientras giras. La puntería te ayuda a encontrar al enemigo. La mano se ilumina cuando hay algo que usar enfrente. En Opciones puedes cambiar la sensibilidad, activar el modo zurdo y la vibración. Se juega mejor en horizontal.
